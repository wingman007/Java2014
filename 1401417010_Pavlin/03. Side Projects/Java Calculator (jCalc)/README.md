Java Calculator (jCalc)
========
#Описание (Version 1.0)

- Извършва събиране, изваждане, умножение и деление с int числа.

- Най-голямото число, което приема е с дължина 10 символа.

- При използване на оператор (+-/x) показва кое е било последното действие.

- Показва съобщение за препълване (прекалено голямо число), както и за деление на 0.

- Всеки бутон има собствен звуков ефект.

#Описание (Version 2.0)

- Съдържа всички характеристики на Version 1.0

- Изчислява факториел, корен квадратен и степенуване.

- Използва double числа и може да се добавя точка (.).

- Най-голямото число, което приема е с дължина 20 символа.

# Bugs

- След получаване на "Error / by zero" или "Error - " (за прекалено голямо число), ако някой 'трол' не изчисти calcDisplay и се опита да извършва операции с тях - гърми (throws Exception).

- При натискане на различни бутони за операции един след друг, сетъра за последно натиснат бутон не работи, защото има зададен if само за числа в calcDisplay.
